# مسمط السيدة زينب (البدرشين) — المنيو الديجيتال ولوحة الأكونت مانجر

مشروع متكامل ومخصص لمطعم **مسمط السيدة زينب (البدرشين)**، يجمع بين واجهة طلب ديجيتال سريعة بدون أي طابع ذكاء اصطناعي مصطنع، ولوحة أكونت مانجر خاصة بصاحب المطعم لإغلاق حسابات اليوم وجرد الوردية (5:00 صباحاً – 12:00 منتصف الليل).

---

## 🌟 المميزات الرئيسية

### 1. تجربة العميل (المنيو الديجيتال — `/`)
- **هوية أصيلة**: مبنية على باليت اللوجو الجديد للشيف **SZ** (أحمر قرمزي `#B91C1C`، أسود فحمي `#181411`، وخلفية ورقية دافئة `#FAF8F2`).
- **43 صنفاً حقيقياً مقسمة عبر 6 أقسام رئيسية**:
  - **ركن الوجبات** (5 وجبات متكاملة مع الفتة والشوربة والعيش).
  - **ركن العائلات والولائم** (7 أصناف بالكيلو: مشكل، كفتة، كبدة، لسان، لحمة راس...).
  - **ركن السندوتشات** (10 أصناف بـ 3 أحجام: صغير / وسط / كبير).
  - **ركن الطلبات** (11 طبقاً ساخناً بأحجام متعددة).
  - **ركن الإضافات** (طواجن فتة بالكوارع، أرز باللحمة والكبدة، سلطات وطحينة).
  - **المشروبات** (مياه معدنية ومشروبات غازية).
- **سلة طلبات ذكية وسريعة**: شريط سفلي عائم يظهر عدد الأصناف والإجمالي مع إمكانية تعديل الكميات وحذف الأصناف.
- **ربط مباشر بالواتساب**:
  - نموذج تأكيد يجمع: الاسم، رقم الموبايل المصري (مع تدقيق صحة الرقم)، نوع الاستلام (دليفري أو تيك أواي)، العنوان والملاحظات.
  - ضغطة واحدة تقوم بحفظ الطلب برقم متسلسل في قاعدة البيانات/التخزين المحلي، وتفتح محادثة واتساب منسقة وجاهزة للإرسال إلى رقم المطعم الرسمي: `01006107924`.

---

### 2. لوحة الأكونت مانجر لصاحب المطعم (`/manager`)
- **حماية برقم سري (PIN)**: الرمز الافتراضي `1234`.
- **نافذة وردية العمل المعتمدة**:
  - فلترة تلقائية تبدأ من **5:00 صباحاً حتى 12:00 منتصف الليل** بتوقيت القاهرة.
  - زر اختياري لطلبات السهرة المتأخرة (12 منتصف الليل حتى 5:00 فجراً).
- **مؤشرات الأداء المالي (KPIs)**:
  - إجمالي المبيعات المؤكدة (صافي الإيراد).
  - عدد الطلبات المؤكدة، قيد الانتظار، والملغاة.
  - قائمة أكثر الأصناف طلباً خلال الوردية مع إيراد كل صنف.
- **إدارة حالات الطلبات**: تأكيد الطلب، إلغاؤه (يُستبعد فوراً من الإيراد الصافي)، أو مسحه.
- **نسخ تقرير تقفيل اليومية**:
  - زر بضغطة واحدة ينسخ ملخصاً نصياً كاملاً للوردية ليتم إرساله في رسالة واتساب لصاحب المطعم أو المحاسب.

## 🛠️ البنية التقنية

- **Next.js (App Router) 14** + **TypeScript**.
- **Tailwind CSS** مع تخصيص كامل للباليت والألوان والخطوط.
- خط **Cairo** عبر `next/font/google` بدون أي وميض أو تأخير.
- تدقيق مدخلات الفورم ورقم الموبايل المصري باستخدام **Zod**.
- **React Error Boundary** لحماية التطبيق من الانهيار.
- ملف **manifest.json** جاهز للتثبيت كتطبيق ويب تقدمي (PWA).

## 🚀 التشغيل والتطوير

### تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`
وللوحة الإدارة: `http://localhost:3000/manager` (الرمز: `1234`)

### بناء المشروع للإنتاج:
```bash
npm run build
npm run start
```
